# MemoAI · AI 图文策展助手（UI/UX 改进版）

这是基于原 v0.2 Demo 改进的本地可运行版本。当前重点完善了创作意图理解、步骤导航、素材导入反馈、候选替换和加工状态。

## 运行环境

- Node.js 18 或更高版本（不需要安装 npm 依赖）
- 浏览器建议使用 Chrome / Edge
- 如需调用阿里云百炼模型，需要自己的 API Key

## 启动方式

1. 将 `.env.example` 复制为 `.env`。
2. 在 `.env` 中填写自己的百炼 API Key 和兼容接口地址。
3. 在项目目录运行：

```bash
node server.js
```

4. 浏览器访问：

```text
http://127.0.0.1:8787
```

不要直接双击 `index.html`。本版本建议通过本地服务访问，以便前端与后端保持同源。

## 本次主要改动

### 1. 创作意图交互
- 第一步增加自然语言输入，不要求用户掌握摄影或设计术语。
- 新增 `/api/intent`，调用文本模型解析主题、表达目标、主体关系、情绪、视觉方向、叙事方式和修图倾向。
- 模型认为存在关键歧义时，可以提出一个澄清问题，默认最多两轮。
- 生成创作意图卡，用户确认后才能进入选图。
- 当模型服务不可用时，提供本地规则生成的初步意图，并明确标注“本地初步整理”，不冒充模型结果。
- 提供“默认智能整理”入口，用户暂时没有明确想法时也可以继续。

### 2. 素材导入
- 支持多选和拖拽导入图片。
- 单个项目最多 100 张，累计计算上限。
- 显示实际导入进度和读取失败数量。
- 重新选择相同文件时可以再次触发导入。
- 导入区域说明原图不会被修改。

### 3. 选图组合
- 候选策略名称和说明改为更贴近当前实际算法的描述。
- 明确说明当前候选主要依据单图质量、场景频次和色相特征，不宣称已经实现完整的两两视觉兼容或叙事优化。
- 替换照片时先展示同类别候选，用户自行选择，不再自动替换成系统挑中的第一张。
- 可以点击图片设置色调参考图。

### 4. 流程与加工
- 阻止用户跳过必要步骤进入选图、加工或导出。
- 重新选择组合或更改色调参考图后，自动使旧加工结果失效。
- 色调处理和文案生成并行执行，并显示对应任务状态。
- 模型文案不可用时明确标注备用示例。
- 导出时禁用重复点击，并处理 Canvas 生成失败的情况。

### 5. 代码和安全改进
- 输出入口统一为 `app.js`，与 `index.html` 引用一致。
- 后端默认仅监听 `127.0.0.1`，避免无意暴露本地 API 代理。
- 移除宽松的跨域访问响应头。
- 静态文件路径使用 `path.resolve` / `path.relative` 校验，并禁止通过静态路由读取 `.env` 文件。
- HTML 渲染前对模型生成的标题、正文、标签和意图摘要进行转义。
- 交付包不包含 `.env`，请自行配置密钥。

## 当前仍然存在的产品/算法边界

- 当前智能成组仍是规则驱动候选：按分类配额结合单图质量、场景频次、色相排序。它还不是完整的图片两两兼容评分、内容互补优化或叙事排序算法。
- 本地质量特征主要用于辅助排序，不能替代专业摄影质量判断。
- 色调迁移是 RGB 统计对齐的简化版本，复杂场景下可能产生肤色或局部颜色偏差，保留原图切换作为回退。
- 素材相似图聚类、废片建议剔除和原始素材分组确认尚未在本版本完整实现。
- 小红书/朋友圈发布仍以导出图片和文案为终点，不自动发布。

## 配置示例

`.env.example` 中只包含占位配置。请勿把真实 `.env` 上传到聊天、代码仓库或公开网盘。若 API Key 曾经被共享，建议在服务商控制台撤销旧 Key 并创建新 Key。
